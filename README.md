# LJT-Homepage

Personal academic homepage for **Junteng Liu**, built with Jekyll and the Academic Pages template.

## Contents

- **About:** personal details, education, research experience, skills, publications, honors, and contact information.
- **Publications:** arXiv preprints and conference papers.

## Local development

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```

The site is deployed with GitHub Pages using the workflow in `.github/workflows/jekyll.yml`.
